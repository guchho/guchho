# `guchho transform`

Transforms source read from stdin and writes the result to stdout.

This is the command line form of the programmatic
[`transform`](../../api/README.md#transform) API: it reads a single input, applies the configured
loader and options, and prints the result.

See [JavaScript & TypeScript](../../guide/javascript-and-typescript.md) and the
[JavaScript API](../../api/README.md) for the shared transform options.
