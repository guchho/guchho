Guchho is open source under the MIT license. The engine is C++20; the npm
package ships a prebuilt binary for each supported platform and a small
JavaScript layer that talks to it.

## Getting help

- Search the [issues](https://github.com/guchho/guchho/issues) before opening a
  new one; if your question is not already filed, open an issue with the command
  you ran, the output you got, and the output you expected.
- Version information for a bug report comes from `guchho info` and
  `guchho --version`.
