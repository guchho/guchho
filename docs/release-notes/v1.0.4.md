# Guchho 1.0.4

**Released 2026-10-11.**

## Packaging

The headline is a new way to hand a build off as one file.

- **`guchho pack`** creates an archive from files and directories, with
  `--format` (`zip`, `tar`, `tar.gz`), `--level` (0–9) and `--allow-overwrite`.
  Each input is stored under its own last path component, and symlinks inside a
  tree are skipped with a warning rather than followed. See
  [`guchho pack`](../reference/cli/pack.md).
- **`pack()`** does the same from JavaScript, returning the archive bytes rather
  than writing a file. See the [JavaScript API](../api/README.md#pack).
- A new [pack recipe](../recipes/pack-a-distribution.md) and the
  [packaging guide](../guide/packaging.md) cover the common shapes.

## Distribution

- The npm publish pipeline gained an **`android-x64`** target, so that platform
  now receives a prebuilt binary like the others.
- Chocolatey and npm packaging metadata were kept in step with the release.

## Engine and tooling

- Updates across the linker, parser and bundler, and a new thread utility used
  by the watching and serving code.
- Test and CMake preset maintenance to keep the suites fast and the builds
  reproducible.

## Upgrading

Nothing here is breaking. Existing configurations build unchanged.

```bash
npm install -g guchho@1.0.4
```
