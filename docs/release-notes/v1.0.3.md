# Guchho 1.0.3

**Released 2026-10-07.**

## Engine

- Refinements across the compiler, CSS, HTML and linker stages, improving
  correctness and the consistency of diagnostics.
- Parser and resolver updates that keep the graph resolution behaviour aligned
  with the documented rules.

## Distribution

- **Chocolatey** packaging was added and verified, so Guchho can be installed on
  Windows through Chocolatey as well as npm.
- The npm publish workflow was corrected, including a fix to the publish
  cascade for the `guchho` package type.

## Docs and contributor tooling

- `CONTRIBUTING.md` and the project `README.md` were updated for the current
  build and test workflow.

## Upgrading

Nothing here is breaking. Existing configurations build unchanged.

```bash
npm install -g guchho@1.0.3
```
