# `guchho clean`

```text
Usage: guchho clean [options]
```

Remove generated build output.

## Options

| Option | Meaning |
| --- | --- |
| `--dry-run` | Show what would be removed without deleting anything. |

Because the default behaviour of this command is to delete, `--dry-run` makes
the first attempt print what it would have done.
